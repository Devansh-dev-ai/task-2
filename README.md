Laundry Wallah
A simple, static laundry-service webpage built with HTML5. The page
introduces the laundry business, displays its services and prices, and
provides a basic booking form and contact email.
Features
- Welcome section with an introduction to Laundry Wallah.
- About section with descriptive placeholder text.
- Image section displaying a laundry-related image from an
  external URL.
- Services section listing:
    - Washing and Drying
    - Ironing and Folding
    - Dry Cleaning
    - Stain Removal
    - Express Services
    - Special Garment Care
- Price table showing the listed service prices.
- Booking form with name, email, and phone fields.
- Contact section with an email link.
  Technologies Used
- HTML5
  Getting Started
1. Download or clone this project.
2. Save the webpage code in a file named index.html.
3. Open index.html in a web browser.
   No build tools or package installation are required.
   Project Structure
   laundry-wallah/
   Booking Form
   The booking form currently contains basic HTML input fields:
- Name (required; minimum 5 and maximum 40 characters)
- Email (required; email format)
- Phone (required)
  Note: The form is currently a front-end form only. It does not
  submit or store bookings because no form action, backend, or database
  has been configured.
  Contact
  Email: info@laundarymart.com
  Notes
- The displayed prices are sample values from the webpage and can be
  edited in index.html.
- The laundry image is loaded from an external URL, so it requires an
  internet connection and may stop working if the source changes.
- The page can be enhanced with CSS for styling and JavaScript or a
  backend service for booking functionality.
